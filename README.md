# Семейный диспетчер

Закрытое семейное веб-приложение поверх Supabase.

## Возможности V1.8

- недельное расписание и получасовая сетка дня с цельными плашками;
- календарь с сентября по декабрь 2026 года с занятиями внутри каждого дня;
- каникулы, поездки, семейные планы, разовые отмены и прекращённые занятия;
- занятость взрослых, подмены и автоматический поиск накладок с учётом дороги;
- базовый будничный режим и полный учёт оплат, пропусков и оставшихся занятий;
- личная JSON-копия рабочих данных после входа.

## Принцип защиты

- в репозитории нет семейных данных, почт, кодов входа или секретных ключей;
- браузер общается только с Edge Function;
- Edge Function хранит `service_role` исключительно на сервере;
- таблицы и старые RPC закрыты для `anon` и `authenticated`;
- сессии хранятся только в виде SHA-256-хэшей и имеют срок действия;
- после пяти неверных попыток действует временная блокировка.

## Структура

- `index.html`, `styles.css`, `app.js` — статическая оболочка;
- `supabase/functions/family-dispatcher/` — защищённый сервер и резервный хост интерфейса;
- `supabase/migrations/` — схема защиты без персональных данных.
- `scripts/embed-static.mjs` — синхронизация интерфейса с резервным хостом Edge Function.

Публикуемый ключ Supabase клиенту не требуется. Для развёртывания Edge Function используется встроенный серверный `SUPABASE_SERVICE_ROLE_KEY`.
